## How this works

<CardGrid>
	<Card title="Write" icon="pencil">
		Add a Markdown file under `src/content/docs/<topic>/`. Copy `templates/note.md` to start.
	</Card>
	<Card title="Publish" icon="rocket">
		Push to `main`. GitHub Actions builds and deploys the site.
	</Card>
	<Card title="Find" icon="magnifier">
		Use search (<kbd>Ctrl</kbd> + <kbd>K</kbd>) or browse topics in the sidebar.
	</Card>
	<Card title="Export" icon="document">
		Print any page and choose **Save as PDF** — only the note content is printed.
	</Card>
</CardGrid>
