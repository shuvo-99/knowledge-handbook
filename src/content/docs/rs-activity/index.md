Welcome! This series is a **6-class introduction to data structures and problem solving**, designed to help students get comfortable with the core ideas **before they take the 220 Data Structures course**.

## Why this series?

Data structures is often the first course where programming stops being only about "making it work" and starts being about **making it work efficiently**. Students who already know the basic vocabulary — arrays vs. lists, time complexity, how to trace a loop — find the course much easier to follow.

The goal of these classes is to:

- **Build intuition** for how common data structures store and access data
- **Learn to analyze code** with time and space complexity (Big-O)
- **Practice problem solving** in the style of competitive programming
- **Get a head start** on the topics covered in the 220 course
